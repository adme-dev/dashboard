## Required tests and evidence

| Risk | Verification |
|---|---|
| Duplicate raster letters | Hide/move each reconstructed text block and visually inspect clean background |
| Wrong content | Exact comparison against approved copy; all commercial facts and legal eligibility unchanged |
| Misregistered masks | Composite extracted layers at source coordinates and compare object silhouette |
| Flattened “editable” text | Edit font and wording, save/reload, inspect native Layer fields |
| Scope/race error | Change selection/delete layer during pending AI response; stale apply rejected |
| Partial failure hidden as success | Provider outage/malformed response/missing mask yields explicit failed or review state |
| Duplicate paid work/import | Repeated key/retry/cancel produces one applied revision and recorded provider attempts |
| Cross-client access | Different authorised identities cannot read/retry/import each other's asset/job |
| Hostile SVG | Script/external URL/foreignObject/entity/path explosion fixtures rejected or safely normalized |
| Export drift | Compare browser and export for typography/effects/positions, verify physical page metadata |
| Invented local setting | Human review: no beach, imaginary dealership facade or implausible human/vehicle scale |

Prefer targeted Vitest suites and browser evidence over implementation-mirroring tests. Do not run an expensive whole production build for documentation-only preparation. Once feature code changes, follow the appropriate repository checks and record pre-existing failures separately.
