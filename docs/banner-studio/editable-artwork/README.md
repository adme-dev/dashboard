Create complete campaign concepts from a brief and approved assets, retain proven styles as reusable recipes, then separate/reconstruct a chosen concept into Banner Studio layers. Existing flat-artwork import remains supported. Select lettering, change its wording with AI and choose native text reconstruction or a reference-led image redraw; preview and apply the scoped replacement with undo. ## Decisions

Build the generation/reconstruction/editor workflow in XeroFlow with replaceable adapters and the existing catalogue. Evaluate Qwen-Layered, Seedream and LayerD for raster decomposition and Quiver for selected SVG assets. Reuse original OEM assets and approved copy wherever available. Do not train a new foundation model in the first release. Vector geometry, AI-redrawn lettering and native text are distinct deliverables.

This pack supersedes the assumptions about automatic reconstruction in the old Dissector specs for this project; it does not supersede existing application security or deployment rules.
