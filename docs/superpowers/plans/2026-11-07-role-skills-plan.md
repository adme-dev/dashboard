# Role skills implementation ledger

1. Backend worker owns fixed workflow definitions, shared roleSkills types, additive migration 505, versioned storage/admin endpoints and authority/PG tests.
2. UI worker owns composer/composable, voice selection transport, staff/admin skill manager, navigation and UI tests.
3. Root owns native read-only specialist tools, guarded official-document lookup, shared native assembly, employee list/submission admission, model-context binding and integration/docs/release.
4. Research/review worker verifies official source commits/licenses/provider docs, then performs independent integrated review. Source findings are recorded separately; no source body is vendored without license review.

Decisions: guided edit-before-send is the default while optional execution preference remains unanswered; no automatic provider execution. Current graph uses colliding legacy node IDs; current source and maintained architecture are authoritative. Role attachments are metadata only and cannot grant tool or Finance authority. Existing catalogue evaluation gates remain enforced.
